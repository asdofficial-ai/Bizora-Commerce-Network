# Bizora Commerce Network

AI-powered commerce infrastructure for local service businesses.

## Product direction

Bizora Commerce Network connects customers with trusted service providers while giving merchants AI-assisted tools for storefronts, customer requests, quotes, orders, and growth.

## Development status

The current V1 inspection build connects merchant listings, customer requests, quotes, messaging, sandbox escrow, disputes, verification, and AI-to-human customer support.

Customer support uses one shared Bizora account session across the site. A customer who is already signed in does not sign in again when opening Support.

The 3D support robot is intentionally shown only on the public homepage. Tapping it opens the dedicated Customer Support page. Other dashboards and workflow pages do not show the floating robot.

Real card processing, bank settlement, and production NIN/BVN verification are not enabled in the inspection build; those flows remain sandbox-safe until approved production providers are connected.
