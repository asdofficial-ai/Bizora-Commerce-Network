# Bizora Commerce Network

AI-powered commerce infrastructure for local service businesses.

## Product direction

Bizora Commerce Network connects customers with trusted service providers while giving merchants AI-assisted tools for storefronts, customer requests, quotes, orders, and growth.

## Development status

V1 is being built in milestones. The first midpoint focuses on the customer marketplace, provider discovery, merchant onboarding, merchant dashboard, and shared application architecture. Payments, production identity verification, disputes, and production backend integrations are intentionally reserved for the second half.
